# Mobile-First UX/UI Skill

## Criterios de Diseño
1. **Ergonomía Móvil**:
   - Botones de asistencia (Presente / Ausente) grandes y accesibles con el pulgar.
   - Navegación principal accesible en barra inferior o encabezado compacto.
2. **Densidad y Claridad**:
   - Tablas de notas con desplazamiento horizontal suave y columna de nombres congelada/fija a la izquierda.
   - Badges visuales claros (ej. etiqueta destacada para alumnos con "Certificado de Trabajo").
   - Semáforo de asistencia: Verde ($\ge 80\%$), Amarillo ($70-79\%$), Naranja ($60-69\%$), Rojo ($<60\%$).
3. **PWA**:
   - Configurar `manifest.json` y Service Worker para permitir instalación en la pantalla de inicio del teléfono.
