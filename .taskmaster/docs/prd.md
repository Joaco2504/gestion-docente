# Product Requirements Document (PRD) — Korum

## 1. Resumen del Producto
**Korum** es una aplicación web progresiva (PWA) para docentes de educación superior que centraliza asistencia, libro de temas, calificaciones, calendario académico, licencias docentes (Decreto 1092) y portal de consulta estudiantil.

## 2. Módulos Core
1. **Gestión de Cátedras y Horarios (`dias_clase` / `horarios`)**
2. **Asistencia y Libro de Temas Digital (`AttendanceTab`, `LibroTemasTab`)**
3. **Motor de Licencias Docentes (`LicenciasDocenteModal`, `licenciasService`)**
4. **Calendario Académico e Institucional (`CalendarioPage`)**
5. **Portal Estudiantil Público ("Mi espacio académico" — `ConsultaAlumnoPage`)**
6. **Panel de SuperAdministración (`SuperAdminPage`)**
